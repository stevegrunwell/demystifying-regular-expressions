# Demystifying Regular Expressions

Regular Expressions ("RegEx") are a powerful tool in any developer's toolbox, but wrapping your mind around its cryptic syntax can be difficult. Anchors, quantifiers, and capture groups? What does it all mean?!

This talk introduces the basic concepts and syntax of RegEx, focusing on the types of patterns developers may see every day. We'll discuss when and where RegEx is a great choice and—perhaps more importantly—where RegEx can cause a world of pain. Attendees will walk away with a greater understanding of how Regular Expressions work and can benefit their projects, regardless of language.
